# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-07-01

### Added

- Production-oriented Docker Compose stack for PostgreSQL, Redis, API, and web.
- Root startup scripts for one-command boot and shutdown.
- Versioned environment examples for API and web.
- Release README updates with quick start, validation, and demo guidance.

### Changed

- API container startup now applies Prisma migrations and seeds demo data automatically.
- Local setup documentation now reflects the release workflow and deployment paths.
